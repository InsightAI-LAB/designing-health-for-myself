Privacy & accessibility

A simple, readable
workshop website.

What this site does

This is a static information website. Its code adds no analytics, advertising, cookies, browser storage, submission forms, embedded third-party content, or external fonts. The navigation works without an account. Essential content and downloadable materials work without JavaScript.

The site does not process health information or send information to an AI service. Clicking an email link opens your email application; nothing is sent until you send a message. Please do not send personal health records.

Hosting and external links

If the organizers publish this package on GitHub Pages, GitHub will serve the files and may process routine technical information, including visitor IP addresses. See the GitHub General Privacy Statement. External websites have their own practices. The site’s lack of analytics does not mean its host keeps no logs.

This organizer-review edition asks search engines not to index it. That request is not a password or access control: a published GitHub Pages site can still be reached and shared. Never place private submissions, organizer correspondence, credentials, or personal health records in the public site or repository.

Accessibility approach

The site uses semantic headings and landmarks, a skip link, keyboard-operable navigation, visible focus indicators, responsive layouts, and a reduced-motion preference. Workshop content is available in HTML and plain text. Visual design examples include text alternatives. Meaning does not rely on color alone.

These choices and automated checks do not constitute a complete accessibility certification. If a page or material creates a barrier, contact the lead organizer at whasan@tuskegee.edu. Explain the relevant page and preferred format; you do not need to disclose a diagnosis.

Workshop participation

The proposed workshop uses fictional scenarios. Speech, typing, writing, facilitator support, and passing are all planned options. No default audio/video recording or research data collection is planned. Attendance is not research consent or permission to publish. Specific conference accommodations remain subject to confirmation with CHI.
